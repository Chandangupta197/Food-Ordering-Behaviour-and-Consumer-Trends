{% if page == 'Privacy' %}

This prototype runs on the computer or server where it is installed. It stores owner account email, business name, and a password hash in a local SQLite database. Passwords are not stored as plain text.

Uploaded datasets

A CSV uploaded by an owner is stored in that local database and associated with that owner's account. The current version keeps one active dataset per account. The dashboard uses those rows to calculate charts, summaries, and filtered downloads.

External page assets

The browser requests fonts from Google Fonts and the chart library from jsDelivr. The app code does not send uploaded CSV contents to those asset providers.

Sharing and deletion

This prototype does not include an external analytics service or account deletion screen. An administrator of the computer/server can access or remove its local database. Do not upload confidential customer details or payment information.

Prototype status

This page describes the current local prototype and is not a substitute for a reviewed privacy policy before a public launch.

{% else %}

Tablewise is an early software prototype for exploring food-ordering data. It is provided for demonstration and analysis and is not a production subscription service.

Data and analysis

You are responsible for having permission to upload the CSV you use. Dashboard results depend on the uploaded data and should be checked before making business decisions. Summaries and statistical comparisons do not establish cause or guarantee future results.

Availability and accounts

Accounts and uploaded files are stored locally in this prototype. There is no paid plan, free-trial billing, service-level commitment, or production backup process yet.

Prototype status

These terms describe the current local prototype and need review before a public launch.
